Common issues

    
Quick fixes for the problems people run into most. Still stuck? Use the Troubleshoot button at the top.

    

      
A value breaks the table layout
Values that contain < or & can be read as HTML and break the table. Turn on Make values HTML-safe and copy the formula again.

      
I get a formula error after turning on HTML-safe
HTML-safe wraps each value in TEXT() and SUBSTITUTE(). If a column type doesn't accept that in your app, turn HTML-safe off for that table and copy the formula again.

      
My column has spaces in its name
That's fine. Type the name exactly as it appears in your table, with or without square brackets, and the generator adds the brackets for you.

      
I need the columns in a different order
Use the up and down arrows next to each column. The table follows the order in the list.

      
The header text looks wrong
Choose Original to keep the header exactly as typed, or UPPERCASE or lowercase to change it. Header text is escaped, so symbols like quotes and < show as typed.
